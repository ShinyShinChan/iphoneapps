How the optimizer thinks
It searches many guillotine layouts, including rotated pieces and both possible first-cut directions. A placement is legal only when each cut can run completely through the current slab/remnant. The cut sequence then walks that cut tree and tells you what stays on the table, what gets set aside, and when a labeled remnant must be reloaded.
