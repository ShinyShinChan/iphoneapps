IMPORTANT
Google Drive is fine for storing/sharing these files, but an iPhone cannot directly install an unsigned .ipa or a PWA from a Drive download. The simplest installation is to host this folder over HTTPS (for example, GitHub Pages), then open the app URL in Safari and use Add to Home Screen > Open as Web App.

All three apps are configured for offline caching after the first load. The Time Card Screenshot button has been converted from its Android-only native bridge to a browser/iPhone-compatible PNG export/share action.
